# CabinMind Client Demo Playbook

Use this guide to run clean, repeatable demos for each CabinMind product.

## 1) Universal Demo Setup (2-3 minutes)

1. Open these tabs first:
   - Marketplace: https://products.devcabin.tech/agents
   - Pricing: https://products.devcabin.tech/pricing
   - Free trial entry: https://products.devcabin.tech/trial
   - Lead demo page: https://products.devcabin.tech/demo
2. Use a private/incognito window so no old localStorage/session data interferes.
3. Set context with one sentence:
   - "I will show exactly what happens from input to output, and what result you should expect in production."
4. Demo framing for clients:
   - Input: what they provide
   - Process: what AI/tooling does
   - Output: what they receive
   - Expectation: speed, limits, and next step

## 2) Product-by-Product Demo Scripts

## AI Lead Researcher

- URL (sales page): https://products.devcabin.tech/agents/lead-researcher
- URL (interactive pitch demo): https://products.devcabin.tech/demo
- URL (free trial): https://products.devcabin.tech/trial

### Steps
1. Open the product page and explain the workflow in one line: ICP -> data enrichment -> validation -> scoring -> export.
2. Open the demo page and enter an ICP statement (or use a preset).
3. Run generation and expand 1-2 leads.
4. Highlight validation/scoring and export path.
5. Close by offering the free trial link.

### Client Expectations
- They should expect real, structured lead records with role/company/contact context.
- Trial expectation: capped free volume (50 leads) at the trial route.
- Production expectation: ongoing usage tied to plan tier and keys/integrations.

## AI Social Media Hub

- URL: https://products.devcabin.tech/agents/social-hub

### Steps
1. Enter a campaign brief.
2. Generate caption.
3. Select channels.
4. In "Demo account connections," leave all disconnected and click Publish Now.

## 3) Suggested Demo Sequence (Best Flow for Most Clients)

1. Start with AI Lead Researcher (highest immediate ROI signal).
2. Move to AI Receptionist or Sales Assistant (conversion story).
3. Show AI Social Media Hub (multi-channel visibility story).
4. Add Website Auditor (technical trust signal).
5. End with Automation Expert or Training (scale/adoption path).

## 4) Common Client Questions (Fast Answers)

- "Can we try before buying?"
  - Yes: https://products.devcabin.tech/trial
- "What does success look like in week 1?"
  - First usable outputs in the first session/day, then workflow tuning.
- "Do we need technical staff?"
  - Usually no for initial use; integration depth determines advanced needs.
- "What if we need help implementing?"
  - Use 1-on-1 AI Training for hands-on rollout.

## 5) Demo Quality Checklist (Before Sending to Client)

1. Every shared URL opens without login blockers.
2. You show at least one real input and one real output per product.
3. You explicitly state one expectation and one limitation per demo.
4. You end with a concrete next step (trial, checkout, or training call).
